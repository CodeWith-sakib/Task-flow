================================================================================
                         INTENTIONAL BUGS (7 TOTAL)
================================================================================

DESIGN GAPS FOR SWE-BENCH:

1. RETRY OFF-BY-ONE
   Location: src/core/retry/RetryManager.ts
   Issue: canRetry() uses <= instead of <
   Impact: Allows one extra retry

2. TIMING TOLERANCE
   Location: src/core/scheduler/TaskScheduler.ts
   Issue: 100ms early execution window
   Impact: Scheduled tasks run before scheduled time

3. QUEUE DUPLICATES
   Location: src/queue/redis/RedisQueueAbstraction.ts
   Issue: No duplicate prevention on enqueue
   Impact: Same task can be queued multiple times

4. NO STRICT LOCKING
   Location: src/workers/Worker.ts
   Issue: No lock mechanism on task dequeue
   Impact: Concurrent execution possible

5. STATE VALIDATION GAPS
   Location: src/core/state/StateTransitioner.ts
   Issue: Missing transition validation
   Impact: Invalid state flows allowed

6. EVENT HANDLER ERRORS
   Location: src/events/EventEmitter.ts
   Issue: No error handling in emit
   Impact: Handler failures not caught

7. ACTIVE COUNT DRIFT
   Location: src/workers/Worker.ts
   Issue: activeCount tracking not perfectly accurate
   Impact: Counter may drift under concurrent loads
